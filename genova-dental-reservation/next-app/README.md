# Dental Reservation / GENOVA

Next.js App Router + React + Tailwind CSS v4. 2026-11 prototype.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Static export is generated in `out/`. If deploying to a separate domain, remove `basePath` and `assetPrefix` in `next.config.ts`.

## Notes
- Images are decorative Unsplash placeholders, not product or customer photography.
- UI and metrics are illustrative (no real patient data or performance claims).
- No source-provider testimonials, partner statistics, or results have been copied.
- The CTAs currently point to a contact selection UI, not a live form. Integrate WordPress/MA form endpoints before launch.
- OEM feature scope, trademark/branding, security policy and legal copy must be signed off before publishing.
